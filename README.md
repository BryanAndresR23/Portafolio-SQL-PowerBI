# 📊 Portafolio de Análisis de Datos — SQL & Power BI

🇪🇸 Español · 🇬🇧 [English below](#-data-analytics-portfolio--sql--power-bi)

Proyectos de análisis de datos de punta a punta: modelado y limpieza en **SQL Server**, análisis de negocio con **T-SQL** y tableros en **Power BI**. Cada proyecto se puede reconstruir desde cero con un solo comando.

## Proyectos

| Proyecto | Descripción | Herramientas |
|---|---|---|
| [💱 International Payments Analytics](international-payments-analytics/README.md) | Pagos internacionales de un banco ficticio: limpieza de datos, **conciliación automática con bancos corresponsales**, SLA, rentabilidad por segmento y 18 preguntas de negocio en SQL. | SQL Server · T-SQL · Power BI · Python |
| [🏦 Automatización de la Conciliación de Deuda Externa](https://github.com/BryanAndresR23/Automatizacion-Conciliacion-Deuda) | Caso real del Banco Central del Ecuador reconstruido con datos ficticios: app en Python/Flask que concilia 9 acreedores × 6 conceptos contra el reporte del Ministerio y explica cada diferencia. | Python · Flask · openpyxl · SQLite |

## Habilidades

- **SQL:** modelado relacional, ETL por capas (staging → core → reporting), funciones de ventana, CTE, `PIVOT`, procedimientos almacenados, controles de calidad de datos.
- **Power BI:** modelo estrella, DAX (inteligencia de tiempo, KPI, formato condicional), diseño de tableros.
- **Negocio:** pagos internacionales, conciliación bancaria, riesgo cambiario, indicadores operativos (SLA).

# 📊 Data Analytics Portfolio — SQL & Power BI

🇬🇧 English · 🇪🇸 [Español arriba](#-portafolio-de-análisis-de-datos--sql--power-bi)

End-to-end data analytics projects: modelling and cleaning in **SQL Server**, business analysis with **T-SQL** and dashboards in **Power BI**. Every project can be rebuilt from scratch with a single command.

## Projects

| Project | Description | Tools |
|---|---|---|
| [💱 International Payments Analytics](international-payments-analytics/README.en.md) | International payments of a fictitious bank: data cleaning, **automatic reconciliation with correspondent banks**, SLA, profitability by segment and 18 business questions in SQL. | SQL Server · T-SQL · Power BI · Python |
| [🏦 Public External Debt Reconciliation Automation](https://github.com/BryanAndresR23/Automatizacion-Conciliacion-Deuda) | Real Central Bank of Ecuador case rebuilt with synthetic data: a Python/Flask app that reconciles 9 creditors × 6 concepts against the Ministry report and explains every difference. | Python · Flask · openpyxl · SQLite |

## Skills

- **SQL:** relational modelling, layered ETL (staging → core → reporting), window functions, CTEs, `PIVOT`, stored procedures, data-quality checks.
- **Power BI:** star schema, DAX (time intelligence, KPIs, conditional formatting), dashboard design.
- **Business:** cross-border payments, bank reconciliation, FX risk, operational KPIs (SLA).
